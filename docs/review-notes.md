# Review Notes Template

Quote Drift is an offline-first daily quote app.

- The daily quote is always free.
- Library browsing, search, saved quotes, and sharing are always free.
- Ads are optional and only unlock one bonus quote for the current day via `One more`.
- The rewarded-ad modal always includes a `Not now` exit.
- No quote is granted unless the rewarded ad completes and the reward is earned.
- Notifications are optional local reminders and the app remains fully usable if permission is denied.
